# Kangaroo riding a bike

Create an original SVG illustration of a kangaroo riding a bicycle. Leave the final image at `/workspace/bike.svg`.

The kangaroo should visibly be on the bicycle, not merely standing beside it. Give the bicycle recognizable wheels, frame, handlebars, and pedals. Make the scene readable at ordinary image-viewing size. Use only self-contained SVG vector elements, with no remote resources, embedded scripts, links, external images, or fonts. You may use the sandbox tools to inspect and revise the file. Do not write Python code as the deliverable.

The harness checks only whether the file is a bounded, well-formed, self-contained SVG and copies it for human review. It does not automatically judge the artistic quality or whether the drawing depicts the requested scene.
